# 14-STREET-PIZZA

New website for 14th Street Pizza Co. (14thstreetpizza.com), built by Nexlyr Solutions.

Static site with no build step. Deploy the repo root as-is (Vercel: framework preset "Other").

```
index.html
css/tokens.css     brand colours, type, spacing
css/site.css       all styles
js/app.js          interactions and animations (GSAP from cdnjs)
data/menu.js       full menu and prices, captured 28 Oct 2026; edit prices here
data/branches.js   16 branches and 1,099 delivery areas
assets/            logo and food photos (webp)
```

Order buttons link to the existing ordering pages on 14thstreetpizza.com.
